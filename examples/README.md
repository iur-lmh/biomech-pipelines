# Ejemplos sintéticos

Estos archivos no contienen datos de personas reales. Sirven para probar los adaptadores:

```bash
biomech parse examples/biobit_ejemplo.csv --out datasets/demo.json
biomech parse examples/mdurance_ejemplo.csv --out datasets/demo_mdurance.json
biomech parse examples/generico_tidy.csv --out datasets/demo_marcha.json
```

Los `sujeto_id` / `paciente_id` son códigos de demostración y se seudonimizan igualmente
al procesarlos.
